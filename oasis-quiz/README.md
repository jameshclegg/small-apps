# Definitely Maybe Him

A ten-question Liam-or-Noel photo quiz. Each round is randomly drawn from a
local library of 60 Creative Commons photos and contains between four and six
Liam questions, with Noel making up the remainder.

## Run

```powershell
cd oasis-quiz
npm start
```

Photo creator, source, and licence details are available from **Photo credits**
in the app.
